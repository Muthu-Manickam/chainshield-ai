# ChainShield AI

Agentic supply-chain intelligence platform. Academic capstone (Group 12), built as a real product:
frontend, backend, database, users and dashboards.

## Map
- [[Decisions]]: every locked or open decision, one note each
- [[Modules]]: code modules and what each owns
- [[Features]]: user-facing features and dashboards
- [[Datasets]]: data sources, facts and caveats
- [[Research]]: proposal, tracker, model reviews
- Locked stack: `STACK.lock.md` in the repo root (summary in [[ADR-001 Simple stack]])

## How to use this vault
- New decision: copy `templates/Decision.md` into `decisions/`, add it to [[Decisions]].
- Status values: `open`, `accepted`, `superseded`, `rejected` (decisions); `planned`, `in-progress`, `done`, `cut` (modules, features).
