# ADR-012 Incident-to-order link

**Status:** open

## Decision
Decide whether to link incidents to orders.

## Context
DataCo has zero orders inside any CrisisMMD 2017 or Nepal 2015 event window; the proposal promises not to present such links as fact.

## Details
Proposed: optional what-if view matching by region only, every result labelled `simulated`; never feeds the risk score.
