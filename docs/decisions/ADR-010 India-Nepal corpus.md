# ADR-010 India-Nepal corpus

**Status:** open

## Decision
Decide whether to use the India-Nepal corpus.

## Context
Both deep reviews found the India half looks template-generated, and the real half is Queensland 2013 floods + Nepal 2015 earthquake, so 'disaster type' is event identity.

## Details
Options: (a) drop it and document the deviation; (b) keep only the Nepal/Queensland half as a labelled limitation; (c) replace with HumAID (19 real events). Needs team/supervisor approval.
